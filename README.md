# sibl

Простой интерпретируемый язык на C. Выполняет скрипты в формате `.sibl` с синтаксисом на основе `:` и `^`.

## Сборка

```bash
make
```

## Использование

```bash
./sibl <file.sibl>  # запуск скрипта из файла
./sibl              # интерактивный режим
```

## Синтаксис

### Вывод
- `putl^текст:` - вывести текст с переводом строки
- `puts^текст:` - вывести текст без перевода строки
- `putw^текст:` - вывести текст с пробелом
- `put^x:` / `putc^x:` - вывести один символ
- `putcl^x:` - вывести один символ с переводом строки
- `puti^выражение:` - вычислить и вывести число
- `putv^имя:` - вывести значение переменной
- `putvl^имя:` - вывести значение переменной с переводом строки

### Переменные
- `v^init^имя^значение:` - инициализировать переменную
- `v^equals^имя^выражение:` - присвоить значение (арифметика/рандом)
- `v^equal^имя^$другое:` / `v^dequal^имя^...` - копировать переменную

### Арифметика
Поддерживается в `v^equals` и `puti`:
- `+` сложение
- `-` вычитание  
- `*` умножение
- `/` деление

Ссылки: `$переменная`, случайное: `#r(min,max)`

### Блоки кода
- `iblock^:` - начать ввод блока. Строки заканчиваются `|`, блок завершается `%`
- `block^:` - выполнить сохранённый блок

### Управление потоком
- `loop^N[код]:` - цикл N раз
- `if^оператор^$a^$b^[код]:` - условие (equals/==, !=, >, <)
- `ee^код:` - выход из программы

### Прочее
- `delay^секунды:` - пауза
- `syscomm^команда:` - выполнить shell команду
- `tputrl^min^max:` - случайное число с переводом строки
- `tputr^min^max:` - случайное число без перевода строки
- `getstr^:` - прочитать строку из stdin

## Пример

```sibl
iblock^:
v^equals^c^+ $a $b:|
putvl^c:|
v^equals^a^$b:|
v^equals^b^$c:|%

v^init^a^0:
putvl^a:
v^init^b^1:
putvl^b:
v^init^c^0:

loop^8[block^]:
ee^0:
```

Выводит числа Фибоначчи.
